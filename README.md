# Заметки (тестовое задание)

SPA на Nuxt 3 (ssr: false) + Pinia + SCSS. Заметки с todo-списками, undo/redo,
черновики и синхронизация вкладок. Данные в localStorage.

## Запуск

Через Docker:

```
docker compose up
```

Приложение на http://localhost:8080.

Локально для разработки:

```
npm ci
npm run dev        # http://localhost:3000
```

Проверки:

```
npm run test       # vitest, логика истории/стора/хранилища
npm run typecheck  # vue-tsc --noEmit
```

## Как устроено, в двух словах

История изменений хранится как стек команд (операция + данные для отката),
а не как снапшоты заметки. Непрерывный ввод копится в pending-буфере и
становится одной командой по blur, паузе 800 мс или любому следующему
действию. Лимит 50 команд, старые вытесняются. Данные лежат в `notes-app:data`
с версией схемы и читаются через `migrate()`: мусор или чужая версия дают
пустое состояние, а не белый экран. Черновик редактора пишется в отдельный
ключ `notes-app:draft` с задержкой в секунду.

## Решения в местах, которые задание оставляло на моё усмотрение

**Пустые значения.** Пустой заголовок при сохранении превращается в
«Без названия», пункты с пустым текстом выбрасываются. Пустота считается после
trim(), уцелевший текст сохраняется обрезанным: заголовок из одних пробелов
выглядит пустым, значит он пустой. Всё это происходит только на сохранении.
Пока печатаешь, только что добавленный пункт законно пуст, и дёргать его
раньше времени незачем.

**Восстановление черновика не восстанавливает историю.** После «Восстановить»
undo/redo пустые. История принадлежит конкретной сессии редактирования. Чтобы
пережить перезагрузку, её пришлось бы сериализовать рядом с черновиком и потом
доказывать, что они не разъехались (черновик пишется по своему таймеру,
история менялась бы отдельно). Рассинхрон дал бы undo в состояние, которого
никогда не было, поэтому восстанавливается текст, а история начинается заново.

**Граница нативного undo.** Ctrl+Z при фокусе в текстовом поле отдаётся
браузеру, у поля свой undo и мешать ему нельзя. Приложение перехватывает
Ctrl+Z только вне текстовых полей, а откат набранного фрагмента на уровне
приложения возможен после его фиксации (blur или пауза). На чекбоксах и
кнопках Ctrl+Z перехватывается, потому что собственного undo у них нет и
уступать некому. Хоткей ловится по `event.code`, а не `event.key`, иначе на
русской раскладке он бы не работал.

**Подтверждение «Отменить» показывается только при наличии правок.** Если
ничего не менялось, модалки нет. Подтверждать отказ от нуля изменений нечего.

**Порядок карточек.** Новые сверху, редактирование заметку наверх не поднимает.
Сортировки в задании нет, придумывать её не стал.

**Черновик экрана создания.** `/notes/new` адресует черновик константой `new`,
а не id, потому что id новой заметки в каждом заходе свой. В типе хранимого
черновика `noteId: string`, без union `string | 'new'`. Компилятор такой union
всё равно схлопывает в `string`, проверок он не добавляет, только видимость
строгости.
